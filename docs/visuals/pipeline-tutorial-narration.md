## 用词约定（踩过的坑）

- **不写「行」**：`行` 是多音字（xíng / háng），TTS 默认按 xíng 读。凡指“搜索记录/条目”的地方一律改写：
  「三行」→「三条」、「每一行」→「每一条」、「十五行」→「十五条」、「entity 行」→「entity 这一种记录」。
- **不写「腿」**：英文 retrieval *leg* 的直译，中文不通顺。统一用 **「通道」**（关键词通道 / 语义通道）。
  `docs/architecture-guide.md` 里原有的「FTS 腿 / 向量腿 / 文本腿」也已一并改成「通道」。

## 换音色 / 重录

```bash
python3 -m venv /tmp/tts-venv && /tmp/tts-venv/bin/pip install edge-tts
/tmp/tts-venv/bin/edge-tts --voice zh-CN-YunyangNeural --rate=-5% \
    --text "旁白文本" --write-media out.mp3
# 可选中文神经音色：Xiaoxiao(女·温暖，当前) / Xiaoyi(女·活泼) /
#                    Yunyang(男·专业) / Yunxi(男·阳光) / Yunjian(男·激昂)
```

> ⚠️ edge-tts 会把旁白文本发送到微软语音服务；生成结果再分发需遵守其服务条款。
> 若要完全离线可换本地神经 TTS（如 Kokoro）。

## 这套视觉是怎么做出来的

`docs/visuals/` 下的自包含 HTML、GIF、MP4、旁白版全部由同一个技能产出，可复用到其他项目：

**`animated-html-video`**（`~/.agents/skills/animated-html-video/`）

| 脚本 | 作用 |
|---|---|
| `scripts/capture_frames.py` | 从自包含 HTML 逐步截图（自动处理 `srcdoc` 吞掉 URL 参数的问题，优先用 headless shell） |
| `scripts/build_media.py` | 帧序列 → MP4 / GIF（含章节标记、背景音、旁白重排时间轴 + 逐章音量校验） |

关键约定写在 `references/html-animation-pattern.md`（动画片段契约：`?step=N&static=1` 静态帧模式、
reveal 必须成对的隐藏/显示规则）与 `references/narration.md`（TTS 路线、多音字与直译的坑、
云端 TTS 的审批与再分发提醒）。
